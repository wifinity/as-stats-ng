# Migrating from archaron/as-stats-ng

This image is a drop-in replacement. The volume layout (`/data/as-stats`), web port (80),
environment variables and `knownlinks` format haven't changed, so existing data carries over.

## 1. Check your config.inc

The web UI's config lives in the volume (`<volume>/config.inc`) and is **not** replaced on
upgrade. The old image shipped a default that pointed at `/data/asstats/` (no hyphen), which
doesn't exist. If yours still has those paths, fix them:

    grep -n 'data/asstats' ./as-stats/config.inc
    sed -i 's|/data/asstats/asstats/|/data/as-stats/|; s|/data/asstats/|/data/as-stats/|' ./as-stats/config.inc

The correct values are:

    $rrdpath = "/data/as-stats/rrd";
    $daystatsfile = "/data/as-stats/asstats_day.txt";
    $daypeerstatsfile = "/data/as-stats/peerasstats_day.txt";
    $knownlinksfile = "/data/as-stats/conf/knownlinks";

Optionally, add the new `'BGP.Tools' => 'https://bgp.tools/as/%as%'` entry to `$customlinks`.

## 2. Back up the volume

    docker compose stop as-stats
    tar czf as-stats-backup-$(date +%F).tgz ./as-stats

## 3. Allow the host to pull from GHCR

GHCR packages are private by default. Either make the package public (Package settings →
Change visibility), or log in on each host with a token that has the `read:packages` scope:

    echo "$TOKEN" | docker login ghcr.io -u <github-user> --password-stdin

## 4. Switch the image

In your compose file, change:

    image: archaron/as-stats-ng:latest

to:

    image: ghcr.io/wifinity/as-stats-ng:latest

Also remove the obsolete `version: '2'` line if present. Then:

    docker compose pull as-stats
    docker compose up -d as-stats

For stricter change control, pin a dated tag (e.g. `:20261102`) or a release tag (`:1.0`)
instead of `:latest`.

## 5. Verify

    docker compose logs -f as-stats      # should show no "No such file" / PHP Fatal errors
    curl -I http://localhost:8080/       # expect HTTP 200

About 2 minutes after start-up, and then hourly, `asstats_day.txt` in the volume should update.
**This is new:** the hourly job never ran in the old image, so the "top AS" pages may show
noticeably more (correct) data than before.

Graphs keep their history because the RRD files are untouched.

## Other differences

- `IPV6=1` binds the NetFlow/sFlow listeners to `::`, so IPv6 exporters can send flows.
- Week and month top-AS tables (`asstats_week.txt`, `asstats_month.txt`) are now generated
  nightly, so the GUI's week/month views populate.
- The image uses an entrypoint script (`/usr/local/bin/entrypoint`) followed by supervisord.
  If you overrode `entrypoint:` in compose, remove that override.
- `bash` and `curl` are no longer in the image. Use `docker exec -it <container> sh`.
- `config.inc` and other `.inc` files can no longer be fetched over HTTP.
- The container reports health status (`docker ps` shows `healthy`).

## Rollback

    # set image back to archaron/as-stats-ng:latest
    docker compose up -d as-stats

The data format is unchanged. `asstats_day.txt` is regenerated by the new image; the old
image can still read it.
